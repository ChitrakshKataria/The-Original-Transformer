# The Original Transformer
Everything in this repo was buildt without the use of AI, Artificial Intelegence was only used as a supporting tool. This project is an implementation of the original transformer interduced in the paper [*Attention Is All You Need*](https://arxiv.org/abs/1706.03762).


## Techstack
- Python - (Pytorch as framework)
- OpenAI tiktoken tokenizer - (Hugging Face: GPT2Tokenizer)
